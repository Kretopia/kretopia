

# Building Company Pro Features for ThriveIN

This plan covers building the 5 company-specific Pro features in phases, from highest impact to lowest. Each phase is designed to be shippable independently.

---

## Phase 1: AI Job Description Generator (Quick Win)

The fastest feature to ship -- companies type a brief and get a polished opportunity posting generated by AI.

**What it does:**
- Add a "Generate with AI" button inside the Post Opportunity dialog
- Company types a rough brief (e.g., "Need a video editor for a music video, $500 budget, remote")
- AI returns a structured title, description, requirements, deliverables, and suggested skills
- Company reviews, edits, and posts

**Technical work:**
- Add an AI generation button in `PostOpportunityDialog.tsx` and `PostOpportunity.tsx`
- Call the existing `generate-content` edge function with a specialized prompt
- Auto-fill the form fields with the AI response
- Gate behind Pro tier using `getTierLimits()` -- free users see a locked preview with upgrade prompt

---

## Phase 2: AI Applicant Ranking (Enhance Existing)

The `OpportunityDashboard.tsx` already has an "Analyze with AI" button. This phase upgrades it into a proper ranking system.

**What it does:**
- Auto-rank applicants when a company opens their opportunity dashboard (Pro only)
- Show match scores, strengths, risks, and a recommended shortlist
- Add filter/sort by AI score, status, and date
- Add a "Shortlist" status between pending and accepted

**Technical work:**
- Refactor `analyzeWithAI()` in `OpportunityDashboard.tsx` to auto-trigger for Pro users
- Add `shortlisted` as an application status option
- Create a summary card at the top: "Top Pick: [Name] -- 92% match"
- Gate: Free users see a blurred preview of rankings with upgrade CTA
- Update `applications` status handling to support `shortlisted`

---

## Phase 3: Applicant Tracking Pipeline (Kanban Board)

Transform the flat applicant list into a visual hiring pipeline.

**What it does:**
- Drag-and-drop Kanban board: Applied --> Shortlisted --> Interview --> Hired --> Rejected
- Each card shows the applicant's avatar, name, role, AI score, and quick actions
- Batch actions: shortlist multiple, send group messages
- Pipeline stats at the top (e.g., "12 Applied, 4 Shortlisted, 2 Interviewing")

**Technical work:**
- Create new `ApplicantPipeline.tsx` component using `@dnd-kit` (already installed)
- Add pipeline stages as columns with drag-and-drop between them
- Database migration: add `pipeline_stage` column to `applications` table (or reuse `status` with new values)
- Gate: Free users get the existing flat list; Pro users get the Kanban view
- Add pipeline view toggle in `OpportunityDashboard.tsx`

---

## Phase 4: Branded Company Page Enhancements

Upgrade company profiles from basic to premium branded pages.

**What it does:**
- Cover photo/banner image upload
- Featured opportunities section on profile
- Team members showcase (link other ThriveIN profiles)
- Company stats (opportunities posted, talents hired, avg response time)
- Custom "About" section with rich text

**Technical work:**
- Database migration: add `cover_image_url`, `team_member_ids` (array), `company_tagline` columns to `profiles`
- Update `ProfileHero.tsx` to render the cover banner for company accounts
- Create `CompanyProfileSections.tsx` with featured opportunities, team grid, and stats
- Gate: Free companies get basic profile; Pro unlocks cover image, team showcase, and stats
- Update profile edit flow in `Settings.tsx` for company-specific fields

---

## Phase 5: Opportunity Performance Analytics

Give Pro companies data on how their postings perform.

**What it does:**
- Dashboard showing per-opportunity metrics: views, applications, conversion rate, time-to-hire
- Trend charts (applications over time)
- Comparison across opportunities
- Insights: "Your best-performing opportunity type is Collaborations"

**Technical work:**
- Database migration: add `view_count` column to `opportunities` table
- Create a view tracking mechanism (increment on `OpportunityDetail` page visit)
- Create `OpportunityAnalytics.tsx` component with charts using `recharts` (already installed)
- Add analytics tab to `OpportunityDashboard.tsx`
- Gate: Free users see basic counts; Pro users get full charts and insights

---

## Feature Gating Strategy (All Phases)

All features use the existing `subscriptionLimits.ts` system:

```text
+------------------+---------------------------+-----------------------------+
| Feature          | Free Company              | Pro Company                 |
+------------------+---------------------------+-----------------------------+
| AI JD Generator  | Locked with preview       | Full access                 |
| AI Ranking       | Basic list view           | Auto-rank + shortlist       |
| Pipeline         | Flat list                 | Kanban drag-and-drop        |
| Branded Page     | Basic profile             | Cover, team, stats          |
| Analytics        | Application count only    | Full dashboard + charts     |
+------------------+---------------------------+-----------------------------+
```

Each locked feature shows a `FeatureLockedBanner` or blurred preview with an "Upgrade to Pro" CTA linking to `/subscription`.

---

## Implementation Order

1. **AI JD Generator** -- small, high-value, uses existing infrastructure
2. **AI Applicant Ranking** -- enhances existing code, visible value
3. **Applicant Pipeline** -- biggest build, high retention impact
4. **Branded Page** -- visual differentiator, drives profile engagement
5. **Analytics** -- requires view tracking data to accumulate first

Each phase is independent and can be shipped, tested, and iterated on before moving to the next.
